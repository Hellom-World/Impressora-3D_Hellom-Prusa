# Diário de Bordo do Projeto Impressora 3D HelloM-Prusa

Este diretório contém o diário de bordo do projeto de construção da impressora 3D HelloM-Prusa. Cada arquivo neste diretório (exceto o `template_entrada.md`) representa uma entrada diária, documentando o progresso, descobertas, desafios e próximos passos.

## Como Usar:

1.  Copie o arquivo `template_entrada.md` para um novo arquivo com o nome `YYYY-MM-DD_titulo_da_entrada.md` (substitua a data e o título).
2.  Preencha as seções do modelo com suas observações do dia.
3.  Utilize a formatação Markdown para organizar suas anotações.

Este diário é uma ferramenta essencial para o processo de aprendizado e para manter um registro detalhado de todas as etapas da construção.
