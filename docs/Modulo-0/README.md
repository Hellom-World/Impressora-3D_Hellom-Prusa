# Módulo 0: Investigação e Reconhecimento de Componentes

Este módulo inaugural adota uma abordagem científica para o reconhecimento e a análise fundamental dos componentes que formam o cérebro e os músculos da impressora 3D. O objetivo não é apenas montar, mas compreender o *porquê* e o *como* de cada parte.

## Fases da Investigação

1.  [Análise de Componentes Eletrónicos](./componentes_eletronicos.md): Uma investigação sobre a função, o princípio de funcionamento e a justificativa para a escolha de cada componente eletrónico.
2.  [Protocolos de Experimentação](./experimentos_eletronicos.md): Uma série de experimentos projetados para verificar o comportamento de cada componente isoladamente, estabelecendo uma base de conhecimento antes da integração.
